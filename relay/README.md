# Посредник между приложением и Т-Банком

Маленькая функция, которая стоит **в России** и одна говорит с API Т-Банка. Всё остальное
приложение (сайт, воркер Telegram) обращается к брокеру только через неё.

**Зачем.** Сертификат API Т-Банка выдан российским национальным центром (Минцифры). Серверы за
рубежом ему не доверяют: любой вызов из Cloudflare, GitHub или Vercel даёт ошибку 526. Сервер в
России с добавленным корневым сертификатом доверяет и работает.

**Что где лежит после установки**

| Что | Где |
|---|---|
| Торговый токен Т-Банка | только в переменных функции (Россия) |
| Ключ посредника `RELAY_KEY` | в функции и в секретах воркера Cloudflare |
| Сайт, база, роботы, Telegram | там же, где и были |

Токен больше не нужен воркеру: его можно удалить из Cloudflare.

## Что умеет

- `GET /health` — жив ли сервис, подключены ли токен и сертификат (без самих секретов);
- `POST /broker/<Сервис>/<Метод>` — для воркера: пересылает разрешённые вызовы брокеру. Список
  методов узкий (счета, позиции, цены, поиск инструмента, выставление и состояние заявки), ничего
  про вывод средств и переводы;
- `POST /order`, `GET /order/config` — те же заявки, что и у воркера, если указать адрес
  посредника прямо в Настройках приложения.

**Стоп-кран.** Переменная `TRADING_DISABLED=true` в функции мгновенно запрещает отправку заявок.
Чтение (счета, позиции) при этом работает.

## Установка на Яндекс Облако (мышкой)

1. **Сертификат.** Зайди на сайт https://www.gosuslugi.ru/crt, скачай корневой сертификат
   «Russian Trusted Root CA» в формате PEM и сохрани как
   `relay\certs\russian_trusted_root_ca.pem` (папку `certs` создай сам). Скачивать только с этого
   сайта.
2. **Архив.** В папке проекта выполни:
   `powershell -ExecutionPolicy Bypass -File relay\build.ps1`
   Получится `relay\dist\traderpro-relay.zip` (и предупреждение, если сертификата в нём нет).
3. **Функция.** В консоли Яндекс Облака: Cloud Functions → «Создать функцию» → среда выполнения
   `nodejs22` (подойдёт и `nodejs18`) → «Редактор» → способ «ZIP-архив» → загрузи архив →
   **точка входа: `relay/yandex.handler`** (в архиве есть файл `relay/yandex.js`, его и ищет Яндекс) → таймаут 30 секунд, память 128 МБ.
4. **Переменные окружения функции:**
   - `TINKOFF_TRADE_TOKEN` — торговый токен Т-Банка (с правом торговли);
   - `RELAY_KEY` — придумай длинную случайную строку (30+ символов) и запиши её;
   - `NODE_EXTRA_CA_CERTS` — `/function/code/certs/russian_trusted_root_ca.pem`;
   - (по желанию) `TRADING_DISABLED` — `true`, чтобы запретить заявки.
5. **Сделай функцию публичной** (иначе она не открывается по адресу) и скопируй её ссылку вида
   `https://functions.yandexcloud.net/…`. Публичность безопасна: без `RELAY_KEY` функция ничего
   не выполняет.
6. **Проверка.** Открой в браузере `ссылка?integration=raw` (путь после идентификатора дописывать нельзя: Яндекс отвечает «invalid functionID», маршрут передаётся параметром, например `ссылка?integration=raw&route=/health`): должно быть `"brokerToken": true`,
   `"relayKey": true`, `"russianCa": true`. Если `russianCa` равно `false`, неверен путь в
   `NODE_EXTRA_CA_CERTS`.
7. **Воркер в Cloudflare** (сайт dash.cloudflare.com): Workers & Pages → `traderpro-telegram-webhook`
   → Settings → Variables and Secrets: добавь переменную `RELAY_URL` (ссылка из пункта 5, **без** `?integration…` и без пути: воркер сам дописывает нужное) и
   секрет `RELAY_KEY` (та же строка). Секрет `TINKOFF_TRADE_TOKEN` можно удалить.
8. **Готово.** В приложении: Настройки → «Проверить готовность», затем Калькулятор.

## Установка на обычный сервер в России (вместо Яндекса)

Нужны Node.js 20+ и любой прокси с HTTPS (nginx, caddy):

```
NODE_EXTRA_CA_CERTS=./relay/certs/russian_trusted_root_ca.pem \
TINKOFF_TRADE_TOKEN=... RELAY_KEY=... PORT=8080 node relay/server.mjs
```

Дальше всё то же, адрес посредника — адрес сервера. Код один и тот же, меняется только обёртка:
`relay/yandex.mjs` для Яндекс Облака, `relay/server.mjs` для сервера.
